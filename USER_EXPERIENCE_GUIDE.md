# FloorTrace v1.0.0-alpha - User Experience Guide

## What Happens When Users Try to Run FloorTrace

### ✅ Scenario 1: User HAS .NET 8.0 Installed

1. User extracts ZIP file
2. User double-clicks `FloorTrace.exe`
3. **Application starts immediately** ✓
4. User can start using FloorTrace right away

---

### ⚠️ Scenario 2: User DOES NOT HAVE .NET 8.0 Installed

1. User extracts ZIP file
2. User double-clicks `FloorTrace.exe`
3. **Windows displays an automatic popup:**

```
┌─────────────────────────────────────────────────┐
│  This application requires .NET                 │
│                                                 │
│  App: FloorTrace.exe                           │
│  Framework: Microsoft.WindowsDesktop.App 8.0   │
│                                                 │
│  [Download .NET]  [Close]                      │
└─────────────────────────────────────────────────┘
```

4. User clicks **"Download .NET"**
5. Browser opens to official Microsoft download page
6. User downloads and installs .NET 8.0 Desktop Runtime (~50 MB, 2-3 minutes)
7. User returns to FloorTrace and double-clicks `FloorTrace.exe` again
8. **Application starts successfully** ✓

## 🔧 Technical Details

### What the Popup Actually Shows

The Windows dialog is generated by the .NET Host and shows:
- Application name: `FloorTrace.exe`
- Required framework: `Microsoft.WindowsDesktop.App 8.0`
- Download button linking to: `https://dotnet.microsoft.com/download`

### Runtime Configuration in FloorTrace

```xml
<TargetFramework>net8.0-windows10.0.19041.0</TargetFramework>
<RollForward>LatestMinor</RollForward>
```

**What this means:**
- Requires .NET 8.0 or later (8.0.0, 8.0.5, 8.0.11, 8.1, etc.)
- Works with Windows 10 version 1903 or later
- Automatically uses newer .NET 8.x versions if available

## 📝 User Feedback Expectations

### Common Questions You Might Get

**Q: "Why do I need to install .NET?"**
A: FloorTrace is built on .NET 8.0, Microsoft's modern application framework. It's a one-time install that many apps use.

**Q: "Is it safe to download .NET?"**
A: Yes! You're downloading directly from Microsoft's official website (dotnet.microsoft.com).

**Q: "How big is the .NET download?"**
A: About 50 MB for the .NET 8.0 Desktop Runtime. It installs in 2-3 minutes.

**Q: "Do I need to install .NET for every app?"**
A: No! Once installed, all .NET apps on your computer can use it.
