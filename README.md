# FloorTrace

![FloorTrace Demo](Assets/FloorTrace.gif)

**FloorTrace** is a Windows application that automatically calculates the square footage of hand-drawn floor plan sketches. Simply load your sketch with room dimensions, and FloorTrace will detect the dimensions, set the scale, trace the perimeter, and calculate the precise area—saving you time and ensuring accuracy.

## Why FloorTrace?

Real estate professionals often receive hand-drawn floor plans from sellers or appraisers that show room dimensions but no total square footage. Manually calculating these areas is time-consuming and error-prone. FloorTrace automates this process:

- **Automatic dimension detection** - Reads room dimensions from your sketch
- **Intelligent perimeter tracing** - Automatically outlines the property boundary
- **Precise calculations** - Delivers accurate square footage measurements
- **Easy corrections** - Manually adjust any detection for perfect results

## Installation

1. Download the latest release from the [Releases page](https://github.com/PairedSales/FloorTrace-Public/releases)
2. Extract the ZIP file to your desired location
3. Run `FloorTrace.exe`

**Requirements**: Windows 10/11 (64-bit)

## How to Use

1. **Load Your Sketch** - Press `Ctrl+V` to paste from clipboard or `Ctrl+O` to open a file
2. **Detect Room** - Click "Detect Room" to automatically find dimensions and set the scale
3. **Trace Perimeter** - Click "Trace Perimeter" to outline the floor plan edges
4. **Calculate Area** - Review the calculated square footage

You can manually adjust the room overlay and perimeter points by clicking and dragging. Double-click to add points, right-click to remove them.

## Features

- 📸 **Easy import** - Load images from files or paste directly from clipboard
- 🔍 **Smart detection** - Automatically reads dimension labels from sketches
- 📏 **Auto-scaling** - Calculates scale from detected room dimensions
- ✏️ **Manual adjustments** - Fine-tune detections with drag-and-drop editing
- 📐 **Accurate measurements** - Precise square footage calculations
- 🖱️ **Interactive interface** - Zoom, pan, and edit with intuitive controls

## Troubleshooting

**Dimensions not detected?**
- Ensure dimension text is clear and readable in your image
- Try adjusting image brightness/contrast before loading

**Perimeter detection incorrect?**
- Manually adjust perimeter points by dragging them
- Double-click to add points, right-click to remove points
